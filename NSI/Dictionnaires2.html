Leçon 01

C'est quoi un dictionnaire ?

Une structure de données fondamentale en Python — et un classique du bac NSI.

🧠

Définition

Un dictionnaire est une collection de paires clé → valeur. Contrairement aux listes (indexées par des entiers 0, 1, 2…), les dictionnaires sont indexés par des clés — qui peuvent être des chaînes, des entiers, des tuples…

La métaphore parfaite

Imagine un vrai dictionnaire de langue : tu cherches le mot (la clé) et tu trouves la définition (la valeur). C'est exactement ça.

{
"nom":"Alice",
"age":17,
"classe":"Terminale",
"notes":[15, 18, 12]
}

Dict vs Liste — quand choisir ?

StructureAccèsUsage typique
Liste []par index numériqueSéquence ordonnée de même type
Dictionnaire {}par clé nomméeObjet avec propriétés nommées
💡 Bonne pratique

Si tu veux stocker des infos sur une entité (un élève, un produit, un personnage…), utilise un dict. Si tu veux une collection de valeurs du même type, utilise une liste.

Propriétés à retenir

🔑

Clés uniques

Deux clés identiques dans un dict, c'est impossible — la deuxième écrase la première.

📦

Valeurs libres

La valeur peut être n'importe quoi : entier, chaîne, liste, un autre dict, une fonction…

⚡

Accès ultra-rapide

Trouver une valeur par sa clé est aussi rapide que d'accéder à une liste par index — O(1).

📋

Ordonné (Python ≥ 3.7)

Depuis Python 3.7, les dictionnaires conservent l'ordre d'insertion des clés.

Dans un dictionnaire Python, qu'est-ce qui doit être unique ?
Les valeurs
Les clés
Les deux
Ni l'un ni l'autre

Leçon 02

Créer un dictionnaire

Trois façons de créer un dict — apprends-les toutes, le bac peut en tester plusieurs.

Méthode 1 — Littérale (la plus courante)

python
# Accolades + paires clé: valeur
etudiant = {
    "nom": "Alice",
    "age": 17,
    "moyenne": 15.5,
    "options": ["NSI", "Math expertes"]
}

print(etudiant)

Méthode 2 — dict() avec mots-clés

python
# Avec la fonction dict()
etudiant = dict(nom="Bob", age=18, moyenne=14.0)

# Attention : les clés deviennent des strings automatiquement
print(etudiant)  # {'nom': 'Bob', 'age': 18, 'moyenne': 14.0}

Méthode 3 — Dictionnaire vide, puis remplissage

python
# Démarrer vide et ajouter ensuite
inventaire = {}  # ou dict()
inventaire["pommes"] = 10
inventaire["bananes"] = 5
inventaire["oranges"] = 8

print(inventaire)
# {'pommes': 10, 'bananes': 5, 'oranges': 8}
⚠️ Piège classique

Si tu utilises deux fois la même clé lors de la création, seule la dernière valeur est conservée — sans erreur !

python
d = {"x": 1, "x": 99}
print(d)  # {'x': 99}  ← la valeur 1 est perdue !

Leçon 03

Lire & accéder aux valeurs

Deux façons d'accéder aux données — et une seule façon de ne pas planter son programme.

Accès direct par clé

python
personne = {"nom": "Lucas", "age": 17, "ville": "Lyon"}

# Accès classique avec []
print(personne["nom"])   # Lucas
print(personne["age"])   # 17

# Si la clé n'existe pas → KeyError !
print(personne["email"])  # 💥 KeyError: 'email'

Accès sécurisé avec .get()

✅ Bonne pratique

Utilise .get(clé) quand tu n'es pas sûr que la clé existe. Retourne None par défaut, ou une valeur de fallback que tu choisis.

python
personne = {"nom": "Lucas", "age": 17}

# .get() sans default → None si absent
email = personne.get("email")
print(email)  # None — pas d'erreur !

# .get() avec valeur par défaut
ville = personne.get("ville", "Inconnue")
print(ville)  # Inconnue

Vérifier si une clé existe — in

python
personne = {"nom": "Lucas", "age": 17}

if "nom" in personne:
    print("La clé 'nom' existe :", personne["nom"])

if "email" not in personne:
    print("Pas d'email renseigné")

Accéder à une valeur imbriquée

python
etudiant = {
    "nom": "Alice",
    "notes": [15, 18, 12],
    "adresse": {"ville": "Paris", "code": "75001"}
}

# Accéder à la 2e note (index 1)
print(etudiant["notes"][1])  # 18

# Accéder à la ville dans l'adresse imbriquée
print(etudiant["adresse"]["ville"])  # Paris

Leçon 04

Modifier & ajouter des clés

Les dicts sont mutables — on peut les modifier à volonté après création.

Modifier une valeur existante

python
joueur = {"pseudo": "Hero42", "score": 100, "vies": 3}

# Modifier une valeur existante
joueur["score"] = 250  # remplace 100 par 250
print(joueur["score"])  # 250

# Incrémenter
joueur["score"] += 50
print(joueur["score"])  # 300

Ajouter une nouvelle clé

python
# La syntaxe est IDENTIQUE à la modification
# Python crée la clé si elle n'existe pas
joueur["niveau"] = 5   # nouvelle clé
joueur["arme"] = "épée"  # nouvelle clé

print(joueur)
# {'pseudo': 'Hero42', 'score': 300, 'vies': 3, 'niveau': 5, 'arme': 'épée'}

Fusionner deux dicts — update()

python
base = {"nom": "Alice", "age": 17}
ajout = {"ville": "Lyon", "age": 18}  # age sera écrasé

base.update(ajout)
print(base)
# {'nom': 'Alice', 'age': 18, 'ville': 'Lyon'}

# Python 3.9+ : opérateur |
resultat = base | ajout
print(resultat)
ℹ️ À retenir

d[clé] = valeur fait les deux : modifie si la clé existe, crée sinon. Python ne fait pas la différence.

Leçon 05

Supprimer des clés

Trois façons de retirer une clé — chacune a son usage.

MéthodeRetourneErreur si absent ?
del d[clé]rien✅ Oui — KeyError
d.pop(clé)la valeur✅ Oui (sans default)
d.pop(clé, default)valeur ou default❌ Non
d.clear()rien❌ Non
python
config = {"debug": True, "port": 8080, "host": "localhost"}

# del — simple suppression
del config["debug"]
print(config)  # {'port': 8080, 'host': 'localhost'}

# pop() — supprime ET récupère la valeur
port = config.pop("port")
print("Port récupéré :", port)  # 8080

# pop() avec default — sans risque
val = config.pop("timeout", 30)  # 'timeout' absent → retourne 30
print("Timeout :", val)

# clear() — vide tout
config.clear()
print(config)  # {}

Leçon 06

Boucles & itération

Parcourir un dictionnaire — la compétence la plus testée au bac.

🔁

Trois vues sur un dict

.keys() → les clés · .values() → les valeurs · .items() → les deux ensemble (en tuples)

Boucle sur les clés (défaut)

python
scores = {"Alice": 92, "Bob": 78, "Clara": 85}

# Parcourir les clés (par défaut)
for nom in scores:
    print(nom)  # Alice, Bob, Clara

# Explicite — même résultat
for nom in scores.keys():
    print(nom)

Boucle sur les valeurs

python
for score in scores.values():
    print(score)  # 92, 78, 85

# Calculer une moyenne
total = sum(scores.values())
moy = total / len(scores)
print(f"Moyenne : {moy:.1f}")  # 85.0

Boucle sur les paires — .items() ⭐ la plus utile

python
# .items() retourne (clé, valeur) → déballage direct
for nom, score in scores.items():
    print(f"{nom} a obtenu {score}/100")

# Filtrer dans la boucle
for nom, score in scores.items():
    if score >= 85:
        print(f"✓ {nom} est reçu avec mention")

Construire un dict avec une boucle

python
prenoms = ["Alice", "Bob", "Clara"]

# Méthode classique
longueurs = {}
for p in prenoms:
    longueurs[p] = len(p)

print(longueurs)  # {'Alice': 5, 'Bob': 3, 'Clara': 5}

# Compréhension de dict — version pro
longueurs = {p: len(p) for p in prenoms}
print(longueurs)  # identique !
⭐ Compréhension de dict — à connaître

Syntaxe : {clé: valeur for élément in itérable} — plus concis et souvent attendu au bac.

Leçon 07

Listes de dictionnaires

La structure la plus utilisée en NSI — représente des tables, des fichiers JSON, des bases de données.

📌 Contexte

Une liste de dicts, c'est comme un tableau : chaque dict = une ligne, chaque clé = une colonne. C'est exactement ce que tu obtiens quand tu lis un fichier CSV ou une API REST.

Créer & accéder

python
eleves = [
    {"nom": "Alice", "age": 17, "note": 88},
    {"nom": "Bob",   "age": 18, "note": 72},
    {"nom": "Clara", "age": 17, "note": 95},
]

# Accéder au premier élève
print(eleves[0])              # {'nom': 'Alice', ...}
print(eleves[0]["nom"])      # Alice

# Modifier la note de Bob (index 1)
eleves[1]["note"] = 80

Parcourir et traiter

python
# Afficher tous les élèves
for eleve in eleves:
    print(f"{eleve['nom']} — note : {eleve['note']}")

# Filtrer : garder les notes >= 80
bons_eleves = [e for e in eleves if e["note"] >= 80]
print(bons_eleves)

# Trouver l'élève avec la meilleure note
meilleur = max(eleves, key=lambda e: e["note"])
print("Meilleur :", meilleur["nom"])

Ajouter un élève

python
nouvel_eleve = {"nom": "David", "age": 17, "note": 79}
eleves.append(nouvel_eleve)
print(f"Classe : {len(eleves)} élèves")

Trier par valeur de champ

python
# Trier par note décroissante
classes_par_note = sorted(eleves, key=lambda e: e["note"], reverse=True)
for e in classes_par_note:
    print(e["nom"], "-", e["note"])

setdefault() — méthode souvent oubliée

python
# setdefault : retourne la valeur si la clé existe,
# sinon l'initialise avec la valeur par défaut
compteur = {}

mots = ["chat", "chien", "chat", "oiseau", "chien", "chat"]
for mot in mots:
    compteur.setdefault(mot, 0)  # initialise à 0 si absent
    compteur[mot] += 1

print(compteur)  # {'chat': 3, 'chien': 2, 'oiseau': 1}

copy() — attention aux pièges

python
original = {"a": 1, "b": [2, 3]}

# Mauvaise façon — les deux variables pointent sur le même objet
mauvaise_copie = original  # PAS une copie !
mauvaise_copie["a"] = 999
print(original["a"])  # 999 — original modifié !

# Bonne façon — copie superficielle
copie = original.copy()
copie["a"] = 1  # ne touche pas original

# Attention : les valeurs mutables (listes) sont toujours partagées
# Pour copie profonde : import copy ; copy.deepcopy(d)

Récap & mémo bac

Opérations essentielles

python — antisèche complète
# ── CRÉER ──────────────────────────────────────────
d = {"clé": "valeur", "n": 42}    # littérale
d = dict(clé="valeur", n=42)        # dict()
d = {}                                   # vide

# ── LIRE ───────────────────────────────────────────
d["clé"]                  # accès direct (KeyError si absent)
d.get("clé")             # sécurisé → None si absent
d.get("clé", 42)        # sécurisé → 42 par défaut
"clé" in d               # True/False
len(d)                   # nombre de paires

# ── MODIFIER / AJOUTER ─────────────────────────────
d["clé"] = "nouvelle"    # modifie OU crée
d.update({"a": 1})       # fusionne

# ── SUPPRIMER ──────────────────────────────────────
del d["clé"]              # supprime (KeyError si absent)
d.pop("clé")             # supprime + retourne valeur
d.pop("clé", None)      # sécurisé
d.clear()                # vide tout

# ── ITÉRER ─────────────────────────────────────────
for k in d:               # clés seulement
for k in d.keys():        # explicite
for v in d.values():      # valeurs seulement
for k, v in d.items():   # les deux ⭐

# ── COMPRÉHENSION ──────────────────────────────────
{k: v*2 for k, v in d.items()}      # transformer
{k: v for k, v in d.items() if v>0}  # filtrer

# ── LISTES DE DICTS ────────────────────────────────
liste[i]["clé"]           # accès
max(liste, key=lambda x: x["champ"])   # max
sorted(liste, key=lambda x: x["champ"]) # trier
[x for x in liste if x["champ"] == v]  # filtrer

Erreurs classiques au bac

❌ Erreur 1 — KeyError

Accéder à une clé absente avec d["clé_absente"] → toujours utiliser .get() ou tester "clé" in d avant.

❌ Erreur 2 — Modifier pendant l'itération

Ne jamais supprimer ou ajouter des clés pendant un for k in d. Itère sur list(d.keys()) à la place.

❌ Erreur 3 — Copie par référence

d2 = d ne copie pas — les deux variables pointent sur le même objet. Utilise d2 = d.copy().

❌ Erreur 4 — Clés en double

Créer un dict avec deux fois la même clé est silencieux : la deuxième valeur écrase la première sans avertissement.
