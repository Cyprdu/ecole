LEÇON 01

C'est quoi un dictionnaire ? ✓

Un dictionnaire est une structure de données qui associe des clés à des valeurs. C'est comme un vrai dictionnaire : tu cherches un mot (la clé) et tu trouves sa définition (la valeur).

Un dictionnaire stocke des paires clé → valeur. Contrairement aux listes qui utilisent des indices numériques (0, 1, 2…), les dictionnaires utilisent des clés de ton choix (texte, nombre, etc.).

Voici comment visualiser un dictionnaire :

Mon dictionnaire "eleve"
"nom"
"Alice"
"age"
17
"classe"
"Term B"
"note"
18.5
clé → valeur  |  clé → valeur  |  clé → valeur

Propriétés importantes :

  • Les clés sont uniques (pas de doublons)
  • Les valeurs peuvent être n'importe quel type : str, int, float, liste, dict…
  • Depuis Python 3.7+, les dictionnaires conservent l'ordre d'insertion
  • Les clés sont généralement des chaînes ou des entiers

⚠️ Un dictionnaire ≠ une liste ! Dans une liste, on accède aux éléments par leur position (0, 1, 2…). Dans un dict, on accède par la clé.

Python 
# Une liste → accès par INDEX
ma_liste = ["Alice", 17, "Term B"]
print(ma_liste[0])  # "Alice" (indice 0)

# Un dictionnaire → accès par CLÉ
mon_dict = {"nom": "Alice", "age": 17, "classe": "Term B"}
print(mon_dict["nom"])  # "Alice" (clé "nom")

LEÇON 02

Créer un dictionnaire ✓

Il existe 3 façons de créer un dictionnaire en Python :

Python — 3 méthodes 
# ━━━ Méthode 1 : Littérale (la plus courante) ━━━
profil = {"pseudo": "Neo", "niveau": 42, "premium": True}

# ━━━ Méthode 2 : dict() avec mots-clés ━━━
profil2 = dict(pseudo="Neo", niveau=42, premium=True)
# ⚠️ avec dict(), les clés sont SANS guillemets

# ━━━ Méthode 3 : Dictionnaire vide, puis remplissage ━━━
profil3 = {}                 # dictionnaire vide
profil3["pseudo"] = "Neo"   # on ajoute clé par clé
profil3["niveau"] = 42

# Vérifier le type
print(type(profil))   # <class 'dict'>
print(len(profil))    # 3 → nombre de paires clé:valeur

Les valeurs peuvent être de n'importe quel type :

Python — Types variés 
inventaire = {
    "joueur": "Alice",           # str
    "hp": 100,                   # int
    "vitesse": 3.5,              # float
    "vivant": True,              # bool
    "armes": ["épée", "arc"],  # liste
    "stats": {"force": 8}       # dict dans dict !
}

Les clés doivent être des types non mutables : str, int, float, tuple. Tu ne peux pas utiliser une liste comme clé (les listes sont mutables).

LEÇON 03

Accéder aux valeurs ✓

Il y a 2 façons d'accéder à une valeur dans un dictionnaire :

Python 
etudiant = {"nom": "Bob", "note": 15, "mention": "Bien"}

# ━━━ Méthode 1 : Crochets [ ] ━━━
print(etudiant["nom"])    # "Bob"
print(etudiant["note"])   # 15

# ⚠️ Si la clé n'existe pas → KeyError !
# print(etudiant["absent"])  → KeyError: 'absent'

# ━━━ Méthode 2 : .get() — PLUS SÛRE ━━━
print(etudiant.get("nom"))       # "Bob"
print(etudiant.get("absent"))    # None (pas d'erreur !)
print(etudiant.get("absent", "?")) # "?" (valeur par défaut)

💡 Conseil BAC : Utilise .get() quand tu n'es pas sûr que la clé existe. Avec les crochets, Python lève une KeyError si la clé est absente.

On peut aussi vérifier si une clé existe avec in :

Python — Tester l'existence 
etudiant = {"nom": "Bob", "note": 15}

# Test avec "in"
if "note" in etudiant:
    print("La note est :", etudiant["note"])  # 15

if "absent" not in etudiant:
    print("Clé 'absent' introuvable")

LEÇON 04

Ajouter & Modifier ✓

La syntaxe est la même pour ajouter une nouvelle clé ou modifier une clé existante :

Python 
scores = {"Alice": 100, "Bob": 85}

# ━━━ AJOUTER une nouvelle clé ━━━
scores["Charlie"] = 92
print(scores)  # {"Alice": 100, "Bob": 85, "Charlie": 92}

# ━━━ MODIFIER une clé existante ━━━
scores["Bob"] = 95   # Bob monte de 85 à 95
print(scores)  # {"Alice": 100, "Bob": 95, "Charlie": 92}

# ━━━ .update() : modifier/ajouter plusieurs clés d'un coup ━━━
scores.update({"Alice": 110, "Dave": 78})
print(scores)
# {"Alice": 110, "Bob": 95, "Charlie": 92, "Dave": 78}

Python ne lève pas d'erreur si tu modifies une clé existante. Il écrase simplement l'ancienne valeur. Utilise in pour vérifier avant si besoin.

Exemple concret : incrémenter un compteur :

Python — Incrémenter 
votes = {"rouge": 3, "bleu": 5}

# Ajouter 1 vote au rouge
votes["rouge"] += 1    # équivaut à votes["rouge"] = votes["rouge"] + 1
print(votes)  # {"rouge": 4, "bleu": 5}

# Ajouter une nouvelle couleur
votes["vert"] = votes.get("vert", 0) + 1
print(votes)  # {"rouge": 4, "bleu": 5, "vert": 1}

LEÇON 05

Supprimer des éléments ✓

Il existe 4 façons de supprimer dans un dictionnaire :

Python 
config = {"theme": "dark", "lang": "fr", "debug": True, "timeout": 30}

# ━━━ 1. del → supprime une clé (KeyError si absente) ━━━
del config["debug"]
print(config)  # {"theme": "dark", "lang": "fr", "timeout": 30}

# ━━━ 2. .pop(clé) → supprime ET retourne la valeur ━━━
langue = config.pop("lang")
print(langue)   # "fr"
print(config)   # {"theme": "dark", "timeout": 30}

# ━━━ 3. .pop(clé, défaut) → sûr si la clé est absente ━━━
val = config.pop("inexistant", "N/A")
print(val)   # "N/A" (pas d'erreur !)

# ━━━ 4. .popitem() → supprime le DERNIER élément inséré ━━━
cle, valeur = config.popitem()
print(cle, valeur)  # "timeout", 30

# ━━━ 5. .clear() → vide tout le dictionnaire ━━━
config.clear()
print(config)  # {}
MéthodeRetourneSi clé absente
del d[k]rienKeyError
d.pop(k)la valeurKeyError
d.pop(k, défaut)la valeur ou défautretourne défaut
d.popitem()(clé, valeur)KeyError si vide
d.clear()None—

LEÇON 06

Boucles sur les dictionnaires ✓

C'est une des parties les plus importantes ! Il y a 3 façons de parcourir un dictionnaire avec une boucle :

Python — 3 types de boucles 
notes = {"Maths": 16, "NSI": 18, "Physique": 14, "Anglais": 15}

# ━━━ 1. Boucle sur les CLÉS (par défaut) ━━━
for matiere in notes:           # ou notes.keys()
    print(matiere)
# Maths, NSI, Physique, Anglais

# ━━━ 2. Boucle sur les VALEURS ━━━
for note in notes.values():
    print(note)
# 16, 18, 14, 15

# ━━━ 3. Boucle sur les PAIRES clé+valeur ━━━ (le plus utile !)
for matiere, note in notes.items():
    print(f"{matiere} : {note}/20")
# Maths : 16/20
# NSI : 18/20
# ...

🏆 La méthode .items() est la plus utilisée en NSI. Elle retourne des tuples (clé, valeur) que l'on déstructure directement dans le for.

Exemple d'algorithme classique : calculer une moyenne :

Python — Algorithme sur dict 
notes = {"Maths": 16, "NSI": 18, "Physique": 14, "Anglais": 15}

# Calculer la moyenne
total = 0
for note in notes.values():
    total += note

moyenne = total / len(notes)
print(f"Moyenne : {moyenne:.1f}/20")  # 15.8/20

# Trouver la meilleure matière
meilleure = max(notes, key=lambda k: notes[k])
print(f"Meilleure matière : {meilleure} ({notes[meilleure]}/20)")

Deux méthodes moins connues mais très utiles :

Python — copy() et fromkeys() 
# ━━━ .copy() : copie indépendante ━━━
original = {"x": 1, "y": 2}
copie = original.copy()
copie["x"] = 99
print(original)  # {"x": 1, "y": 2} — inchangé !
print(copie)     # {"x": 99, "y": 2}

# ⚠️ Attention : si on faisait copie = original (sans .copy())
#    les deux pointent vers le MÊME objet !

# ━━━ dict.fromkeys() : initialiser avec une liste de clés ━━━
matieres = ["Maths", "NSI", "Physique"]
notes_vides = dict.fromkeys(matieres, 0)
print(notes_vides)  # {"Maths": 0, "NSI": 0, "Physique": 0}

⚠️ Piège classique NSI : copie = original ne copie pas le dict ! Les deux variables pointent vers le même objet. Utilise toujours .copy() pour une vraie copie indépendante.

La compréhension de dictionnaire (dict comprehension) — souvent au bac :

Python — Dict Comprehension 
# Syntaxe : {clé: valeur for variable in itérable}

# Carré des 5 premiers entiers
carres = {n: n**2 for n in range(1, 6)}
print(carres)  # {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}

# Filtrer : ne garder que les notes >= 10
notes = {"A": 16, "B": 8, "C": 14, "D": 5}
admis = {k: v for k, v in notes.items() if v >= 10}
print(admis)   # {"A": 16, "C": 14}

# Inverser clés et valeurs
original = {"a": 1, "b": 2, "c": 3}
inverse = {v: k for k, v in original.items()}
print(inverse)  # {1: "a", 2: "b", 3: "c"}

LEÇON 08

Dictionnaires imbriqués ✓

Un dictionnaire peut contenir d'autres dictionnaires comme valeurs. C'est extrêmement courant pour représenter des données complexes (JSON, bases de données…).

Python — Structure imbriquée 
# Un dict d'élèves, chaque élève est lui-même un dict
classe = {
    "Alice": {"age": 17, "notes": [15, 18, 16], "redoublant": False},
    "Bob":   {"age": 18, "notes": [12, 9,  14], "redoublant": True},
    "Carol": {"age": 17, "notes": [18, 20, 17], "redoublant": False},
}

# ━━━ Accès imbriqué : dict[clé1][clé2] ━━━
print(classe["Alice"]["age"])        # 17
print(classe["Bob"]["notes"][0])    # 12 (1ère note de Bob)
print(classe["Carol"]["redoublant"]) # False

# ━━━ Modifier une valeur imbriquée ━━━
classe["Bob"]["age"] = 19

# ━━━ Ajouter une clé dans un sous-dict ━━━
classe["Alice"]["mention"] = "Bien"

Comment parcourir un dict imbriqué :

Python — Boucle sur dict imbriqué 
# Calculer la moyenne de chaque élève
for nom, infos in classe.items():
    notes = infos["notes"]
    moyenne = sum(notes) / len(notes)
    print(f"{nom} → moyenne : {moyenne:.1f}/20")

# Trouver les élèves redoublants
redoublants = [nom for nom, infos in classe.items()
               if infos["redoublant"]]
print("Redoublants :", redoublants)

💡 Les dicts imbriqués sont la base du format JSON (utilisé partout sur le web). En Python, json.loads() transforme une chaîne JSON en dictionnaire Python automatiquement !
